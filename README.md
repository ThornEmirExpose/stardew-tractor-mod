## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Auto-Till** | Drive over untilled dirt to automatically till it with your hoe |
| **Auto-Water** | Water crops automatically as the tractor passes over them |
| **Auto-Harvest** | Collect ready crops without stopping — just drive through your fields |
| **Highly Configurable** | Enable or disable each tool function and adjust speed independently |
